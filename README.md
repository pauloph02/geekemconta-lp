# LP Geek em Conta → Telegram

Página estática mobile-first que manda o visitante do anúncio Meta para o canal **https://t.me/geekemconta**. Hospede a pasta `lp/` em qualquer host estático (Netlify, Cloudflare Pages, GitHub Pages, S3+CloudFront, Vercel static): basta apontar o document root para esta pasta e servir `index.html`. Não precisa de build; os assets (logo + 4 fotos de produto) já estão em `assets/`. Depois de publicar, use a URL pública como destino do anúncio e confira no celular que o botão abre o Telegram.
